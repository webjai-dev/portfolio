## 📌 เกี่ยวกับโปรเจกต์นี้ (About This Project)
Repository นี้คือ Source Code สำหรับ **Official Landing Page** ของ WebJai (เว็บใจ) ซึ่งถูกออกแบบมาโดยเน้นประสบการณ์การใช้งานบนโทรศัพท์มือถือเป็นหลัก (Mobile-First Design) ด้วยโครงสร้าง UI ที่ให้ความรู้สึกเหมือนกำลังใช้งานแอปพลิเคชัน (App-like UI) มีแถบนำทางด้านล่าง (Bottom Navigation) และระบบ Modal แบบสไลด์ขึ้น (Bottom Sheet)
## ✨ บริการของเรา (Our Services)
เราให้บริการรับทำเว็บไซต์ครอบคลุมทุกสเกล:
 * 🎓 **วัยเรียน / โปรเจกต์จบ:** เน้นโค้ดคลีน เป็นระเบียบ พร้อมอธิบายโครงสร้างให้เอาไปพรีเซนต์ผ่านฉลุย ในราคานักศึกษา
 * 💼 **ธุรกิจตั้งไข่ / SME:** เว็บเซลล์เพจ, E-Commerce, เว็บโปรไฟล์บริษัท เน้นดีไซน์สวย รองรับมือถือ เพื่อเพิ่มความน่าเชื่อถือและยอดขาย
 * 🚀 **สเกลอัปองค์กร:** รับพัฒนาระบบหลังบ้าน, Custom Web Application, ERP, CRM ที่รองรับข้อมูลจำนวนมากและมีความปลอดภัยสูง
## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
โปรเจกต์นี้ถูกพัฒนาขึ้นด้วยเทคโนโลยีที่เรียบง่ายแต่ทรงพลัง เพื่อความรวดเร็วในการโหลดและการทำ SEO:
 * **HTML5:** โครงสร้างเว็บแบบ Semantic พร้อมฝังแท็ก SEO (Meta, Open Graph, Schema.org)
 * **Tailwind CSS (CDN):** จัดการสไตล์และ Layout แบบ Utility-first เพื่อความรวดเร็วและยืดหยุ่น
 * **Bootstrap Icons:** ชุดไอคอนที่สะอาดตาและเป็นมาตรฐาน
 * **Vanilla JavaScript:** จัดการ Interaction ต่างๆ ภายในเว็บ เช่น การเลื่อนหน้าจอ (Smooth Scroll), Bottom Sheet Modal และระบบคัดลอกข้อความ
## 🚀 วิธีการใช้งาน (Getting Started)
เนื่องจากโปรเจกต์นี้เป็น Static HTML ล้วน จึงไม่ต้องติดตั้ง Build Tools ใดๆ ให้ยุ่งยาก:
 1. Clone repository นี้ลงในเครื่องของคุณ:
   ```bash
   git clone https://github.com/your-username/webjai-portfolio.git
   
   ```
 2. ดับเบิลคลิกเปิดไฟล์ index.html ด้วย Web Browser ใดก็ได้ (Chrome, Safari, Edge)
 3. *แนะนำ:* หากใช้ VS Code สามารถติดตั้ง Extension **Live Server** เพื่อดูผลลัพธ์แบบ Real-time เวลาแก้ไขโค้ดได้
